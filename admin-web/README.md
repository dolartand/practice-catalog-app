# Admin Web

Админ-панель для управления каталогом фарфора: товары, категории, заказы, отзывы. Построена на React + TypeScript.

## Быстрый старт

Требования: Node.js 18+, pnpm.

1. Установить зависимости:

   ```bash
   pnpm install
   ```

2. Запустить приложение:

   ```bash
   pnpm dev
   ```

3. Открыть в браузере: [http://localhost:3000](http://localhost:3000).

Полная инструкция — [docs/frontend/web/02-architecture.md](../docs/frontend/web/02-architecture.md).
