## Быстрый старт

Требования: Node.js 18+, npm.

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Запустить приложение:

   ```bash
   npm run start
   ```

3. Запустить эмулятор или подключить устройство:

   - Для Android:

     ```bash
     npm run android
     ```

   - Для iOS:

     ```bash
     npm run ios
     ```

Полная инструкция — [docs/frontend/mobile/08-roadmap.md](../docs/frontend/mobile/08-roadmap.md).
