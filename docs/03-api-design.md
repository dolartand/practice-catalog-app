# 03. Дизайн API

> Статус: черновик
> Версия: 0.1
> Связанные документы: [01. Архитектура](01-architecture.md), [02. Модель данных](02-domain-model.md), [04. Аутентификация](04-auth.md), [05. Заказы](05-orders.md)
> Полный машиночитаемый контракт — `openapi.yaml` (фаза 2). В этом документе — соглашения, перечень ресурсов и примеры ключевых контрактов.

## 1. Соглашения

### Базовый URL

Все пути начинаются с `/api/v1` (версия в пути). Пример: `https://api.example.com/api/v1/products`.

### Методы и коды ответов

| Метод | Назначение | Типовые коды |
|---|---|---|
| `GET` | Чтение | 200, 404 |
| `POST` | Создание | 201, 400, 409, 422 |
| `PATCH` | Частичное обновление | 200, 400, 404, 409 |
| `PUT` | Замена/идемпотентное создание | 200, 201, 409 |
| `DELETE` | Удаление | 204, 404 |

### Аутентификация

- Заголовок `Authorization: Bearer <accessToken>` для защищённых эндпоинтов.
- Отсутствие/невалидность токена → `401 Unauthorized` (Problem Details).
- Недостаточные права → `403 Forbidden`.
- Публичные эндпоинты помечены «без авторизации».

### Пагинация (page-based)

- Параметры: `page` (0-based, по умолчанию 0), `size` (по умолчанию 20, максимум 100).
- Ответ-конверт:

```json
{
  "items": [ ... ],
  "page": 0,
  "size": 20,
  "total": 143,
  "totalPages": 8
}
```

### Сортировка

Параметр `sort` (один из фиксированного набора, по умолчанию `newest`):

| Значение | Смысл |
|---|---|
| `price_asc` | по цене со скидкой по возрастанию |
| `price_desc` | по цене со скидкой по убыванию |
| `rating_desc` | по рейтингу (сначала выше) |
| `newest` | по дате создания (сначала новые) |
| `discount_desc` | по размеру скидки (сначала большая) |

### Ошибки (RFC 9457 Problem Details)

Все ошибки возвращаются в едином формате:

```json
{
  "type": "https://api.example.com/errors/not-found",
  "title": "Ресурс не найден",
  "status": 404,
  "detail": "Товар с id 123 не найден",
  "instance": "/api/v1/products/123",
  "traceId": "f7a2c9...",
  "errors": { "priceFrom": ["должно быть неотрицательным"] }
}
```

| Поле | Описание |
|---|---|
| `type` | Машинный идентификатор ошибки (URI) |
| `title` | Человекочитаемый заголовок |
| `status` | HTTP-код |
| `detail` | Детальное описание |
| `instance` | Путь запроса |
| `traceId` | Идентификатор для трассировки (совпадает с `X-Request-Id`) |
| `errors` | Карта ошибок валидации полей (поле → список сообщений); только при 400/422 |

Маппинг статусов:

| HTTP | Сценарий |
|---|---|
| 400 | Невалидный запрос, ошибки валидации полей |
| 401 | Отсутствует/просрочен/невалиден токен |
| 403 | Недостаточно прав (роль) |
| 404 | Ресурс не найден / не существует |
| 409 | Конфликт состояния (товар неактивен, повторный отзыв, повторная регистрация email) |
| 422 | Семантическая ошибка бизнес-правила (остаток меньше запрошенного) |

### Общие правила

- Даты и время — ISO-8601, UTC (`2026-08-17T12:00:00Z`).
- Деньги — целые копейки (`priceCents`), числа без плавающей точки.
- `null` в ответе исключается; пустые коллекции — `[]`.
- Чувствительные поля (пароль, hash) никогда не возвращаются.
- Все запросы, меняющие состояние, идемпотентны по смыслу; для повторов клиент использует один и тот же `X-Request-Id`.

## 2. Публичные эндпоинты (без авторизации)

### Категории

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/v1/categories` | Дерево активных категорий (вложенность children) |

Параметры: нет. Ответ — массив узлов `{ id, name, slug, imageUrl, sortOrder, children: [...] }`.

### Товары

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/v1/products` | Поиск/список товаров с фильтрами |

Параметры запроса:

| Параметр | Тип | Описание |
|---|---|---|
| `q` | string | Поиск по названию, артикулу, серии (pg_trgm) |
| `categoryId` | UUID | Категория, включает подкатегории |
| `priceFrom`, `priceTo` | integer (копейки) | Диапазон цены со скидкой |
| `series` | string | Серия/коллекция |
| `type` | string | Тип изделия |
| `inStock` | boolean | Только с остатком > 0 |
| `onlyDiscounted` | boolean | Только со скидкой |
| `sort` | enum | Сортировка (см. раздел 1) |
| `page`, `size` | integer | Пагинация |

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/v1/products/{id}` | Карточка товара: основные поля, SKU с остатками, изображения, рейтинг |

Ответ: 200 с карточкой; 404 — товар не найден или неактивен.

### Отзывы товара

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/v1/products/{id}/reviews` | Список опубликованных отзывов (пагинация, сортировка по новизне) |

Параметры: `page`, `size`. Ответ: конверт с `{ id, userFirstName, rating, text, createdAt }`.

## 3. Эндпоинты пользователя (USER)

### Аутентификация

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/v1/auth/register` | Регистрация: email, пароль, имя; создаёт User (role=USER) |
| `POST` | `/api/v1/auth/login` | Вход: email + пароль → пара токенов |
| `POST` | `/api/v1/auth/refresh` | Ротация refresh-токена → новая пара токенов |
| `POST` | `/api/v1/auth/logout` | Отзыв refresh-токена (пометка revoked) |

Детали токенов — в [04-auth.md](04-auth.md).

### Корзина

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/v1/cart` | Содержимое корзины: SKU, названия, цены, суммы |
| `POST` | `/api/v1/cart/items` | Добавить SKU: `{ skuId, quantity }`; повторное добавление увеличивает количество |
| `PATCH` | `/api/v1/cart/items/{id}` | Изменить количество: `{ quantity }` (≥ 1) |
| `DELETE` | `/api/v1/cart/items/{id}` | Удалить позицию |

Ошибки: 422 — остаток меньше запрошенного; 409 — товар/SKU неактивен.

### Заказы

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/v1/orders` | История заказов пользователя (пагинация, сортировка по дате) |
| `POST` | `/api/v1/orders` | Оформление заказа из корзины: `{ customerName, customerPhone, deliveryCity, deliveryAddress, comment }` |
| `GET` | `/api/v1/orders/{id}` | Детали заказа (доступен только владельцу) |
| `POST` | `/api/v1/orders/{id}/cancel` | Отмена заказа (только статус NEW) |

Ошибки: 404 — заказ не найден/не принадлежит; 409 — отмена невозможна по статусу; 422 — корзина пуста, остатки изменились.

### Избранное

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/v1/favorites` | Список товаров в избранном (пагинация) |
| `PUT` | `/api/v1/favorites/{productId}` | Добавить товар (идемпотентно) → 200/204 |
| `DELETE` | `/api/v1/favorites/{productId}` | Удалить из избранного → 204 |

### Отзывы

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/v1/products/{id}/reviews` | Оставить отзыв: `{ rating: 1..5, text }`; только покупатель, один на товар |
| `PATCH` | `/api/v1/reviews/{id}` | Изменить свой отзыв (оценку/текст) |
| `DELETE` | `/api/v1/reviews/{id}` | Удалить свой отзыв |

Ошибки: 403 — не покупатель; 409 — отзыв уже оставлен; 404 — отзыв не найден или чужой.

## 4. Эндпоинты администратора (ADMIN)

### Категории

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/v1/admin/categories` | Создать категорию `{ name, slug, parentId?, description?, imageUrl?, sortOrder }` |
| `PATCH` | `/api/v1/admin/categories/{id}` | Обновить категорию |
| `DELETE` | `/api/v1/admin/categories/{id}` | Soft delete (запрещён, если есть активные товары/подкатегории) → 409 |

### Товары и SKU

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/v1/admin/products` | Создать товар (все фиксированные поля, цены в копейках) |
| `PATCH` | `/api/v1/admin/products/{id}` | Обновить товар (пересчёт цены со скидкой, событие product.updated) |
| `DELETE` | `/api/v1/admin/products/{id}` | Soft delete |
| `POST` | `/api/v1/admin/products/{id}/skus` | Создать вариант SKU `{ name, article, priceCents?, discountPercent?, stockQty }` |
| `PATCH` | `/api/v1/admin/skus/{id}` | Обновить SKU (цена, скидка, остаток) |
| `DELETE` | `/api/v1/admin/skus/{id}` | Деактивация SKU (не удаление) |

### Изображения

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/v1/admin/products/{id}/images` | Загрузка изображения: multipart `file` + `position`; главное — `isMain: true` |
| `PATCH` | `/api/v1/admin/images/{id}` | Смена позиции/главного изображения |
| `DELETE` | `/api/v1/admin/images/{id}` | Удаление изображения (файл удаляется из MinIO) |

Ограничения файла: JPEG/PNG/WebP, до 10 МБ. Ответ — 201 с метаданными изображения.

### Заказы (оператор)

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/v1/admin/orders` | Все заказы с фильтром по статусу (пагинация) |
| `PATCH` | `/api/v1/admin/orders/{id}/status` | Смена статуса: `{ status }` (только по допустимым переходам, см. [05-orders.md](05-orders.md)) |

### Отзывы (модерация)

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/v1/admin/reviews` | Все отзывы, фильтр `isModerated` |
| `PATCH` | `/api/v1/admin/reviews/{id}/moderation` | Одобрить/скрыть: `{ isModerated: true/false }` |

Скрытые отзывы не возвращаются в публичных списках и не учитываются в рейтинге.

## 6. Ограничения и лимиты

| Область | Лимит |
|---|---|
| `size` (пагинация) | максимум 100 |
| email | до 320 символов |
| пароль | от 8 до 72 символов |
| наименования товара/категории | до 300/200 символов |
| артикул | до 64 символов, уникален |
| комментарий к заказу | до 1000 символов |
| текст отзыва | от 1 до 2000 символов |
| количество в корзине | от 1 до 999 на позицию |
| изображение | JPEG/PNG/WebP, до 10 МБ |
| телефон | до 30 символов |
