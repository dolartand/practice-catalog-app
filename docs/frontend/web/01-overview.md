# 01. Обзор веб-админки

> Статус: Запланировано (не начато)
> Версия: 0.1
> Связанные документы: [Mobile Roadmap](../mobile/08-roadmap.md), [Backend 01. Архитектура](../../backend/01-architecture.md), [Backend 03. API](../../backend/03-api-design.md)

## 1. Назначение

Веб-сайт для администраторов завода: управление товарами и складом.

## 2. Ожидаемый охват

- CRUD товаров, категорий (дерево), SKU.
- Управление остатками (stockQty по SKU).
- Медиа: загрузка/порядок изображений (MinIO на бэкенде).
- Заказы: просмотр, смена статусов (NEW → CONFIRMED → DELIVERED / CANCELLED) — триггерит события для клиентов.
- Роли: только ADMIN — авторизация через существующий бэкенд.

## 3. Ограничения и решения

- Стек не выбран (кандидаты: React + Vite / Next.js; UI-библиотека обсуждается отдельно).
- Используется существующий REST API `/api/v1` без изменений; при нехватке админских эндпоинтов — расширение бэкенда фиксируется в его ADR.
- **Старт — только после завершения мобильного приложения** (блоки 8–11 закрыты).
