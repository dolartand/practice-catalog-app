## 2. Зависимости от бэкенда

Расширения API, ранее согласованные как «ожидаемые контракты»
([03 §6](03-api-integration.md)), **реализованы** (commit `7c1aaee`); флаги
`features.gaps.*` в коде включены и оставлены как рубильник отката:

| Расширение | Блокировал | Статус |
|---|---|---|
| `GET /admin/products?status=…`, админ-карточка | W2: управление неактивными товарами | [x] Реализовано |
| `GET /admin/categories` (полное дерево) | W4: возврат скрытых категорий | [x] Реализовано |
| `GET /admin/orders/{id}` (позиции + история) | W5 UX: состав заказа у оператора | [x] Реализовано |
| Данные автора/товара в `GET /admin/reviews` | W6 удобство колонок | [x] Реализовано |

## 3. Definition of Done (на блок)

- Экран соответствует разделу доков; ошибки API показываются понятными
  сообщениями (Problem Details), поля форм подсвечиваются по `errors`.
- Мутации инвалидируют кэш по матрице; подтверждения деструктивных действий.
- `lint` / `typecheck` чистые.
- Проверен сценарий вручную против локального бэкенда (`docker-compose up`,
  сидированный админ).

## 4. После v1 (бэклог)

- Включение флагов по мере реализации расширений бэкенда.
- Экспорт заказов в CSV; печать накладной.
- Управление пользователями (если появится соответствующий админ-API).
- Тёмная тема AntD (token'ы уже подготовлены к этому).
