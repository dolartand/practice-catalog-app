## 1. Модерация отзывов (`/reviews`)

### Очередь

AntD Table над `GET /admin/reviews?isModerated=&page=&size=`.

Табы-фильтр: **На модерации (isModerated=false) | Опубликованные (true) | Все**.
По умолчанию — «На модерации» (это рабочая очередь).

Колонки:

| Колонка | Источник | Примечание |
|---|---|---|
| Товар | `productId` → публичная карточка `GET /products/{id}` | ленивый резолв названия через Query, кэш по id; для неактивных товаров — короткий UUID |
| Автор | `userId` | до расширения API — сокращённый UUID моноширинно [03 §6.4] |
| Оценка | `rating` | звёзды 1–5 |
| Текст | `text` | с раскрытием длинных (Tooltip/expand) |
| Создан | `createdAt` | локальное время |
| Статус | `moderated` | Tag «На модерации» / «Опубликован» |

Сортировка серверная: новые сверху.

### Действия

| Действие | Вызов | Результат |
|---|---|---|
| Одобрить | `PATCH /admin/reviews/{id}/moderation {isModerated: true}` | отзыв появляется в публичном списке и входит в рейтинг |
| Скрыть | `{isModerated: false}` | исчезает из публичного списка, исключается из рейтинга; доступен повторный показ |

- Оба действия доступны из строки таблицы и из модалки просмотра.
- Скрытие опубликованного — confirm («Отзыв будет скрыт с витрины и исключён
  из рейтинга товара»).
- После мутации — invalidate `['reviews']`, `['stats']`, `['product', productId]`
  (рейтинг на карточке пересчитан бэкендом).
- Удаления отзыва админом нет (только автор может удалить) — так задумано
  в контракте.

### Краевые случаи

- Отзыв удалён автором между получением списка и действием → `404` →
  notification + рефетч очереди.
- Товар удалён → карточка вернёт `404`: в колонке «Товар» показываем
  «(товар недоступен)» и продолжаем модерацию — текст отзыва самодостаточен.
- Повторное применение того же статуса — no-op со стороны бэкенда (перезапись
  флага), UI просто обновляет строку.

## 2. Дашборд (`/dashboard`)

Без нового эндпоинта статистики — агрегируем `total` пагинационных конвертов
(запросы по `size=1`, читаем только `total`):

| Карточка | Запрос | Поле |
|---|---|---|
| Активные товары | `GET /products?size=1` | `total` |
| Заказы NEW | `GET /admin/orders?status=NEW&size=1` | `total` |
| Заказы CONFIRMED | `…status=CONFIRMED…` | `total` |
| Заказы DELIVERED | `…status=DELIVERED…` | `total` |
| Заказы CANCELLED | `…status=CANCELLED…` | `total` |
| Отзывы на модерации | `GET /admin/reviews?isModerated=false&size=1` | `total` |

Представление: AntD Statistic-карточки; блок заказов дополнен быстрыми
ссылками на соответствующий таб `/orders?status=…`. Карточка «Отзывы на
модерации» подсвечивается при `total > 0`.

Обновление: `refetchInterval: 60s` для ключа `['stats']`; после мутаций
заказов/отзывов/каталога — инвалидация согласно [03 §5].

Расширение позже (когда появится эндпоинт статистики): выручка за период,
топ товаров — место в коде зарезервировано тем же ключом `['stats']`.
