## 2. Блок 8 — Избранное

- `entities/favorite` + FavoriteStore (fetch, add, remove; локальный Set id для мгновенного тоггла — optimistic update).
- features/toggle-favorite: «сердечко» на ProductCard и детальной странице.
- pages/favorites — список избранного, доступ из профиля.
- **Критерий**: сердечко переключается мгновенно и переживает перезапуск приложения.

## 3. Блок 9 — Отзывы

- `entities/review` + ReviewStore; widgets/product-reviews (список на детальной странице, пагинация).
- features/write-review: форма (рейтинг звёздами + текст); право проверяется по DELIVERED-заказу (403 при попытке либо предскрытие — UX обсудить).
- features/edit-review, features/delete-review.
- **Критерий**: купивший и получивший заказ может оставить/изменить/удалить отзыв; остальные — только читают.

## 4. Блок 10 — Профиль

- pages/profile/menu: текущий профиль-экран превращается в меню (профиль, заказы, избранное, настройки, о заводе).
- features/edit-profile под PATCH /me.
- Settings переезжает на вложенный роут `app/(tabs)/profile/settings.tsx`.
- pages/about — статический экран контактов завода (локали, без API).
- **Критерий**: профиль — полноценный хаб без потери функциональности Settings.

## 5. Блок 11 — Полировка и сверка с контрактом

- Прогон сценария «каталог → корзина → заказ → доставка (эмуляция смены статуса) → отзыв».
- Все Problem Details сценарии (400/401/403/404/409/422) дают понятные сообщения в UI.
- Ревизия design-экспериментов (Tamagui на Settings, GlassEffect): решить, что остаётся на весь app.
