# 11. Полировка и сверка с контрактом (блок 11)

Кодовая полировка выполнена; финальный сценарный прогон «каталог → корзина → заказ →
доставка → отзыв» остаётся за ручным тестом на устройстве.

## Что сделано

### Дизайн-ревизия (решение по экспериментам)
- **Tamagui свёрнут и удалён из приложения** (зависимости `tamagui`, `@tamagui/config`
  сняты): SettingsPage переписана в общем стиле (unistyles-карточки + NavLinkRow,
  как хаб профиля), ThemeSwitcher/LanguageSwitcher переведены на RN+unistyles без
  потери анимации бегунка.
- **GlassCard остаётся** примитивом (используется в change-password), но починен:
  определение поддержки liquid-glass — ленивое вычисление вместо setState-в-эффекте.
- Единый визуальный язык: карточки radius 16, бордер `theme.colors.border`,
  заголовки 24/800, кнопки 48–54px radius 14–16, тосты над таб-баром.

### Централизованные ошибки
- `shared/lib/show-error-toast.ts`: единая точка превращения ошибок в понятный тост.
  Статусы 400/403/404/409/422 → локализованные ключи `errors.http.*`; сеть/неизвестное
  → общие тексты. Сырые английские title/detail бэкенда в UI больше не светятся.
- Подключено вместо «молчаливых» catch: добавление в корзину (включая 422 по остаткам),
  изменение количества/удаление позиций корзины, optimistic-тоггл избранного.
  Специфичные сценарии отзывов (403/409/404) сохраняют собственные более точные тосты.

### Константы вместо строковой магии
- `src/shared/api/endpoints.ts` — все пути REST API (структурно по контроллерам
  бэкенда); при изменении контракта правится один файл.
- `src/shared/lib/routes.ts` — все строки навигации expo-router (`ROUTES`), включая
  билдеры `product(id)` / `profile.order(id)`; заменены по всему приложению.
- `src/shared/lib/storage/storage-keys.ts` (`STORAGE_KEYS`) — ключи kvStorage/
  SecureStore: сессия, язык, кэш избранного, мои отзывы, контакты чекаута.
- `src/shared/lib/constants.ts` — числовые константы из контракта: размеры страниц
  (20/10), параметры полной синхронизации избранного (100×5), лимиты валидации
  (имена ≤100, телефон ≤30, текст отзыва ≤2000).
- Цвета → токены темы unistyles: `star` (рейтинг-звёзды), `warning`
  (сила пароля/жёлтая семантика), `scrim` (подложка кнопок поверх фото) —
  вместо разбросанных hex/rgba.

### Порядок и границы слоёв
- **AuthGuard переехал** из shared/ui (нарушение границы shared→entities) в
  `entities/session/ui` — теперь импортирует только свой стор.
- **PasswordStrengthMeter**: useAnimatedStyle вынесен из map-колбэка в дочерний
  компонент Segment (реальное нарушение правил хуков).
- Репозиторий: `eslint . --fix` — порядок импортов приведён везде; остаток —
  0 ошибок и ~16 предупреждений только намеренных (mount-only эффекты) и косметических
  (`import/no-named-as-default-member` у axios/i18next).
- typecheck чистый.

## Чек-лист ручного прогона (на устройстве)

- [ ] Гость: каталог/поиск/фильтры работают, сердечко → тост-приглашение.
- [ ] Логин → восстановление сессии при рестарте, сердечки/корзина на месте сразу.
- [ ] Каталог → товар → SKU → корзина → чекаут → заказ создан.
- [ ] Смена статуса заказа на DELIVERED (админкой) → отзыв создаётся, висит «На модерации»;
      после модерации появляется в списке и влияет на рейтинг.
- [ ] Редактирование/удаление отзыва; после перезапуска отзыв всё ещё «мой».
- [ ] Профиль: PATCH имени/фамилии/телефона; очистка телефона (null) переживает re-login.
- [ ] Логаут: сессия сброшена, локальные данные (корзина/избранное/мои отзывы) очищены.
- [ ] Все экраны в светлой и тёмной теме.
