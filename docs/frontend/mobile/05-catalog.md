# 05. Каталог: товары, категории, фильтры, детальная страница

> Статус: Реализовано (блоки 2–4, 6)
> Версия: 0.1
> Связанные документы: [02. Доменная модель](02-domain-model.md), [03. Интеграция с API](03-api-integration.md), [Backend 02. Доменная модель](../../backend/02-domain-model.md)

## 1. Товары под SKU (блок 2)

- Типы `Product` / `ProductSku` переписаны под контракт: цены в копейках, скидка, характеристики (серия, тип, декор, материал, вместимость, вес, габариты, страна), рейтинг.
- `ProductCard` / `ProductCardSkeleton`: новые поля + рейтинг (звезда + ratingCount).
- Пагинация `ProductStore.fetchList/fetchMore` — под конверт `{ items, page, size, total, totalPages }`.
- Автодополнение поиска — без отдельного эндпоинта: переиспользует `productApi.getList({ query, size: 5 })`; в дропдауне мини-карточки (фото + название + цена).

## 2. Категории как дерево (блок 3)

- `entities/category`: рекурсивный тип с `children[]`.
- `CategoryStore.fetchTree()` + плоский геттер для поиска категории по id (хлебные крошки).
- UI навигации по дереву: drawer категорий (`widgets/category-drawer`) — пользователь доходит до товаров конкретной подкатегории.

## 3. Фильтры (блок 4)

Форма `FiltersModal` (features/filter-products):

| Поле | Контрол |
|---|---|
| priceFrom / priceTo | два инпута |
| series | свободный текстовый ввод |
| type | select из захардкоженного справочника (сервиз, чайная пара, чашка, блюдце, тарелка, ваза, статуэтка, сувенир, сахарница, молочник) |
| inStock / onlyDiscounted | тумблеры |
| sort | select: price_asc / price_desc / rating_desc / newest / discount_desc |

Поток: локальное состояние формы → применение → сборка query-параметров → `productStore.fetchList(params)`. На кнопке фильтров в каталоге — бейдж количества активных фильтров.

## 4. Детальная страница товара (блок 6)

- `pages/product-detail`: галерея изображений, характеристики, выбор SKU (если >1), добавление в корзину с учётом выбранного SKU, рейтинг.
- Роут: `app/(tabs)/catalog/[productId].tsx`.

**Критерии приёмки**: карточки и автодополнение показывают корректные данные; любая комбинация фильтров корректно уходит в query; переход с карточки открывает детальную страницу.
