# Frontend-документация

Документация клиентских приложений проекта «Каталог фарфора» (porcelain-shop).

## Структура

| Папка | Назначение | Статус |
|---|---|---|
| [mobile/](mobile/) | Мобильное приложение для клиентов (Expo / React Native) | Блоки 0–7 реализованы, 8–11 в плане |
| [web/](web/) | Веб-сайт для админов: управление товарами и складом | Запланировано |

## Приоритет разработки

1. **Мобильное приложение** — завершается в первую очередь (блоки 8–11 из плана).
2. **Веб-админка** — стартует только после завершения мобильного клиента.
