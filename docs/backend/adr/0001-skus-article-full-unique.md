# ADR 0001. Уникальность артикула SKU — полный unique-индекс

## Статус

Принято

## Контекст

[02-domain-model.md, раздел 8] определяет для `product_skus` индекс `uk_skus_article` как «unique, partial». Частичные unique-индексы в проекте используются вместе с soft delete (`WHERE deleted_at IS NULL`), но у `product_skus` поля `deleted_at` нет — SKU не удаляется физически и мягко, а деактивируется (`is_active = false`).

Возможные трактовки:

1. Полный unique по `article` (уникальны все SKU).
2. Partial `WHERE is_active` — уникальны только активные SKU; деактивированный освобождает артикул.

Вариант 2 создаёт риск конфликта: деактивировать SKU с артикулом A, создать новый с тем же артикулом, затем реактивировать старый → два активных SKU с одним артикулом (или ошибка в неожиданном месте).

## Решение

Использовать полный unique-индекс: `CREATE UNIQUE INDEX uk_skus_article ON product_skus (article)`.

## Последствия

- Артикулы SKU глобально уникальны независимо от активности.
- Повторное использование артикула после деактивации невозможно без переименования.
